# Offline Setup Installers

Place required offline installation packages in this directory before setting up on an offline machine.

### Required Files
1. **Microsoft ODBC Driver for SQL Server (`msodbcsql`):**
   * File: `msodbcsql17.msi` or `msodbcsql18.msi`
   * Official Download: [Microsoft ODBC Driver Download](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server)

2. **SQL Server Express Installer:**
   * File: `SQLEXPR_x64_ENU.exe` or extracted folder `SQLEXPR_x64_ENU/`
   * Official Download: [Microsoft SQL Server Express Downloads](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)
