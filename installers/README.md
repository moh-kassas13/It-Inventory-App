# Offline Setup Installers

Place required offline installation packages in this directory before running the offline setup script.

### Required Files
* **SQL Server Express Installer:** `SQLEXPR_x64_ENU.exe` or extracted folder `SQLEXPR_x64_ENU/`
* **Official Download:** [Microsoft SQL Server Express Downloads](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)
